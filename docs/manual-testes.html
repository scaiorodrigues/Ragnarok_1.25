Manual de Testes

Subir o servidor, os 10 bots e verificar cada sistema — Ragnarok 1.25

Antes de tudo

01Colunas hardcore no bancoUMA VEZ

Sem isso a Folha de Yggdrasil não funciona — o script depende de hardcore_dead.

mysql -u root -p < sql-files/hardcore_columns.sql

O script já imprime as colunas criadas ao final. Se aparecerem as três, está pronto.

02Sua conta como AdminUMA VEZ

Os comandos @ deste manual exigem grupo 99. Troque SEU_USUARIO pelo login que você usa:

UPDATE `login` SET `group_id` = 99 WHERE `userid` = 'SEU_USUARIO';

Precisa relogar para valer.

03Firewall da LANUMA VEZ

Botão direito em firewall_lan.bat → Executar como administrador. Libera 6900/6121/5121 só para a rede local.

04Os 10 personagensUMA VEZ

O OpenKore cria a conta sozinho (sufixo _M), mas não o personagem. Entre com o client em cada conta e crie o char com o nome exato:

HC_Novice01      HC_Merchant01     HC_Knight_STR01
HC_Priest_Supp01 HC_Wizard_INT01   HC_Hunter_DEX01
HC_LK_STR01      HC_HW_INT01       HC_Sniper_Trap01
HC_Creator_FCP01

A senha está no config.txt de cada bot, em bots/<nome>/.

Subir

05ServidorSEMPRE
runserver.bat

Sobe login, char e map. O web-server não é mais necessário — o use_web_auth_token foi desligado.

Confira no console do map-server: as linhas de carga dos bancos. Se algum YAML novo tiver erro, ele reclama ali e não no jogo.

Testar cada sistema

Telegraphs de solo@

Três skills ganharam marcação visível. Invoque um monstro que as usa e observe o chão durante o cast:

# Chuva de Meteoros — campo de fogo, 1,3 s de aviso
@monster B_KATRINN      // High Wizard Kathryne, MVP

# Tempestade de Raios — campo de vento, 1,5 s
@monster PHARAOH        // Pharaoh, MVP

# Escuridão Sagrada — área escura, 1,1 s
@monster LORD_OF_DEATH  // Lord of the Dead, MVP
O que confirmar: a área aparece no chão antes do dano, e some quando ele acontece. O tempo de aviso é o próprio cast — nada foi adicionado, só ficou visível.
Encantamento no drop@
# mate o monstro e veja o item que cai
@monster ORK_WARRIOR 5

# ou pegue direto e confira as opções
@item Executioner_ 1

Todo equipamento deve vir com exatamente um encantamento. Clique com o botão direito no item para ver as opções.

O @item passa por getitem, então também é encantado — é o mesmo caminho das quests.
Refino do ferreiro abrindo posições@
@jobchange Whitesmith
@allskill
@item Oridecon 50
@item Elunium 50
@item Executioner_ 1

Use Refinar Arma e acompanhe: a cada 2 níveis (+2, +4, +6, +8) aparece a mensagem "O refino despertou um novo encantamento!" e uma opção nova no item.

Confirme também que a falha não destrói. Refine além do seguro várias vezes: o item deve perder um nível, nunca sumir.
Maestria por raça@
# o contador sobe a cada morte; 10.000 por tier
@monster PORING 100

# consultar progresso
@warp prontera 155 183

Fale com o Mestre das Crônicas. Para testar sem farmar 10 mil, ajuste o marco em npc/custom/hardcore_titulos.txt (.marco = 10000) e recarregue com @reloadscript.

Folha de Yggdrasil@

Precisa de um personagem morto na conta. O caminho rápido:

# 1. marque um char da sua conta como morto
UPDATE `char` SET `hardcore_dead` = 1
WHERE `name` = 'NOME_DO_CHAR';

# 2. com outro char da MESMA conta
@item Leaf_Of_Yggdrasil 1

Use a folha. Deve abrir a lista dos mortos da conta. Confirme os dois lados:

Cancelar não consome. Escolha "Guardar a folha" e verifique que ela continua no inventário. Depois reviva de verdade e veja o char voltar a aparecer na seleção.

Morte permanente@
Use um personagem descartável. A morte é definitiva — é esse o teste.
@monster BAPHOMET

Ao morrer, o personagem deve ser bloqueado na seleção. Com a Carta Osiris equipada, ele entra em Limbo de 24 h em vez da morte definitiva.

Recarregar sem derrubar

Depois de editar arquivos, nem sempre é preciso reiniciar:

ComandoRecarrega
@reloadscriptNPCs e scripts — o mais usado
@reloaditemdbItens, cartas, encantamentos
@reloadmobdbMonstros e drops
@reloadskilldbSkills e telegraphs
@reloadbattleconfConfigurações de batalha
Alteração em src/ exige recompilar e reiniciar. Nenhum reload cobre C++.
Comandos disponíveis para o grupo 99 (Admin). A lista completa está em conf/atcommands.yml. O símbolo é @ para comandos sobre si e # para aplicar em outro jogador — por exemplo #item HC_LK_STR01 Executioner_ 1.
